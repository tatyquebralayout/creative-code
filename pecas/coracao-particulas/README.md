# Coração de partículas

Coração anatômico claro pulsando enquanto partículas douradas se soltam dele em 3D.
*Light anatomical heart pulsing while golden particles drift off it in 3D.*

Autora: Tatiana Barros

---

## Origem · Origin

Esta peça veio do repositório [umataldetatiana/Project_Cubos_Threejs](https://github.com/umataldetatiana/Project_Cubos_Threejs), da outra conta de Tatiana Barros. Ajustes pra galeria: o script agora roda como módulo, com three.js 0.159 (a versão do `package.json` original) por CDN em vez da `node_modules`; o caminho do `SVGLoader` virou relativo; as partículas foram escaladas e centralizadas sobre o coração e voltam pra ele quando se afastam; tudo para com "reduzir movimento".

*This piece came from [umataldetatiana/Project_Cubos_Threejs](https://github.com/umataldetatiana/Project_Cubos_Threejs), Tatiana Barros's other account. Gallery tweaks: the script now runs as a module, with three.js 0.159 (the original `package.json` version) from a CDN instead of `node_modules`; the `SVGLoader` path is relative; particles are scaled and centered on the heart and return to it when they drift away; everything stops with "reduce motion".*
